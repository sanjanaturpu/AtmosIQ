
# 🌐 AtmosIQ – Climate Intelligence Dashboard

An interactive climate analytics dashboard for exploring India's historical temperature and rainfall patterns from 1991 to 2024.

## Features
- Interactive regional climate analysis
- State-wise temperature comparisons
- Historical temperature heatmap
- Annual rainfall trends and rankings
- Temperature vs precipitation scatter plot
- Interactive geographical visualization

## Technologies
- Python, Pandas, NumPy, Xarray, h5py
- GeoPandas and Shapely
- HTML, CSS and JavaScript
- Plotly.js and Leaflet
- NetCDF, CSV and GeoJSON

## Data Sources
India Meteorological Department (IMD).

Temperature archive:
https://www.imdpune.gov.in/cmpg/Griddata/Max_1_Bin.html

https://www.imdpune.gov.in/cmpg/Griddata/Min_1_Bin.html

## Running the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Start a local development server (for example, VS Code Live Server).
4. Open `index.html` in the browser.

Note: Raw NetCDF datasets are not included in this repository. The dashboard uses the processed CSV files in `data/processed/`.
