Data Sources

AtmosIQ uses processed historical gridded climate datasets for India, including annual precipitation and temperature records. State boundaries are supplied as GeoJSON.

Analysis Period

The primary analysis period is 1991–2024. Charts use available observations within this period and retain gaps where source data is missing.

Spatial Aggregation

State temperature statistics use area-weighted grid-cell averages. India-wide precipitation summaries use valid grid cells and account for spatial cell area.

Limitations

Coverage varies by variable, state and year. Missing observations are not treated as zero or estimated. Results describe the supplied datasets and are not forecasts.
